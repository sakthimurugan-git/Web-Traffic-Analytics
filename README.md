# Web Traffic Analytics

## Project Objective
This project analyzes website traffic data to understand user behavior, engagement patterns, and conversion trends.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Features
- Page Views
- Session Duration
- Bounce Rate
- Traffic Source
- Time on Page
- Previous Visits
- Conversion Rate

## Analysis Performed
- Data Cleaning
- Statistical Analysis
- Traffic Source Analysis
- Conversion Analysis
- Correlation Analysis
- Data Visualization

## Visualizations
- Page Views Distribution
- Traffic Source Comparison
- Conversion Rate Analysis
- Correlation Heatmap
- User Engagement Analysis

## Key Insights
1. Some traffic sources perform better in conversions.
2. Longer session duration improves engagement.
3. Bounce rate impacts conversion performance.
4. Returning visitors tend to interact more.
